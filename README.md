# TaskStudent

## Descripción

TaskStudent es una aplicación móvil desarrollada en Flutter que ayuda a estudiantes a organizar tareas, actividades, proyectos y fechas de entrega desde una sola plataforma.

La aplicación permite gestionar tareas académicas, organizar materias, crear notas de texto, generar notas mediante voz utilizando reconocimiento de voz y administrar actividades de forma sencilla e intuitiva.

Este proyecto fue desarrollado como parte de la asignatura **Implementa Aplicaciones Móviles Multiplataforma** como proyecto final de la materia.


## Características Principales

* Inicio de sesión.
* Gestión de tareas.
* Creación, edición y eliminación de tareas.
* Marcado de tareas completadas.
* Prioridades (Alta, Media, Baja).
* Fechas límite de entrega.
* Organización por materias.
* Búsqueda de tareas.
* Filtros de tareas.
* Notas de texto.
* Notas por voz (Speech to Text).
* Perfil de usuario.
* Estadísticas de productividad.
* Soporte para múltiples idiomas:

  * Español
  * Inglés
  * Francés
* Modo oscuro.

## Módulos de la Aplicación

### Login

Permite acceder al sistema mediante usuario y contraseña.

### Dashboard

Muestra un resumen general de tareas y accesos rápidos a los diferentes módulos.

### Tareas

Permite crear, editar, eliminar y completar tareas académicas.

### Materias

Permite organizar actividades por asignaturas.

### Notas

Permite registrar notas escritas.

### Notas de Voz

Permite convertir voz a texto mediante reconocimiento de voz.

### Perfil

Permite modificar el nombre mostrado del usuario.

### Configuración

Permite cambiar idioma, activar modo oscuro y cerrar sesión.


## Objetivo del Proyecto

Desarrollar una aplicación móvil que ayude a estudiantes a mejorar la organización de sus actividades académicas mediante herramientas digitales fáciles de utilizar.
